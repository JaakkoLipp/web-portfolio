### Palette role mapping (Claude's call)

Rosé Pine pine (`#31748f`) and muted (`#6e6a86`) fail WCAG AA as small text on base (3.4:1).
They are only used for decoration. Text roles use colors that pass.

| Role | Rosé Pine color | Contrast on base |
| --- | --- | --- |
| Body text | text | 13.4 |
| Secondary text | subtle | 5.5 |
| Links, directories, path, OK | foam | 10.4 |
| Brand, prompt user and host, cursor, git refs | rose | 10.5 |
| Executables, commit types | iris | 8.4 |
| Git hashes, warnings | gold | 10.8 |
| Errors | love | 6.1 |
| Decoration only (vim tildes, logo shadow, aurora) | muted, highlight high, pine | n/a |
